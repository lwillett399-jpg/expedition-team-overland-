# ETO white social icons

Transparent, scalable SVG icons for the ETO hero and footer.

- `youtube-white.svg`
- `instagram-white.svg`
- `facebook-white.svg`
- `x-white.svg`

Recommended display size: 20–24 px. Each SVG includes a white fill and an accessible title.

```html
<img src="images/social/youtube-white.svg" width="20" height="20" alt="YouTube">
```
